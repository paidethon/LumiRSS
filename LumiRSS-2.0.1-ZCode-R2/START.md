## 目标已经被暂停时

确认不是你有意暂停，并准备继续后发送：

```text
/goal resume
```

这是用户主动恢复目标的命令，不是允许 ZCode 自行绕过你按下的停止按钮。若还处于 Plan 模式，先切换到适合本任务的实际执行权限模式；该设置与 Goal 不同。

## 新 Agent 的会话边界

新定义若需要新会话才能原生加载，让 ZCode先保存 checkpoint 和已完成代码；当前会话仍可用现有 Agent 继续业务。确实需要重开时，在新会话发送：

```text
读取本任务包 MASTER.md 和唯一 checkpoint。复核新工具原生注册状态，然后从记录的未完成批次继续同一2.0.1目标。保留所有worktree和证据；不重复预备、不重建台账、不重复已合入任务。只汇报真实硬阻塞，不把恢复会话当成项目完成。
```

随后按实际状态更新或恢复 Goal。不能仅靠提示词保证自动创建新会话，也不能保证800项固定在一夜完成。

## 检查本任务包是否齐全

在任务包目录执行：

```bash
python3 check_plan.py
```

该命令只检查 400/400 编号、清单同步、20/10/10 工具数和名称；输出 PLAN_OK 不代表任何业务任务已经完成，更不是部署证明。

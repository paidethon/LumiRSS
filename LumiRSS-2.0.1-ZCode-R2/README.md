# LumiRSS 2.0.1 R2 执行任务包

先阅读 START.md，按其中的执行说明和 /goal replace 接管既有任务。不要再运行旧的“只做工具预备”指令。

| 文件 | 用途 |
|---|---|
| START.md | 可复制的执行说明、目标替换与恢复命令 |
| MASTER.md | 持续执行、证据、工具、架构、UI、文档、SSH 和发布规范 |
| TASKS-800.md | 完整列出的 400 FIX 与 400 NEW，按领域分批读取 |
| tasks.json | 与 Markdown 一致的机器可读候选清单，初始不宣称完成 |
| tools.json | 20 个新 Skills、10 MCP、10 Agent 的真实入口与应用要求 |
| check_plan.py | 本任务包结构检查，不是软件或部署验收 |
| VALIDATION.txt | 本包生成时的结构检查结果 |
| SHA256SUMS | 文件完整性摘要；不是签名或发布来源证明 |

计数口径：本版本累计400+400，延续原001–200，补充201–400。不是强迫重做所有旧工作，也不是假称已经发现400个真实缺陷。不存在或重复的候选按 MASTER.md 一换一替代并留证据。

研究日期：2026-09-28。公共 main、本地 release 分支和生产不是同一状态。源站、依赖版本、许可及生产信息须执行时再核验。

20个Skills名称与旧清单不同；MCP中Storybook为preview，Git/Memory为官方参考实现。仓库stars不等于实际使用人数。未在用户环境安装、调用或部署这些内容；任务包只有研究和执行指令。

本包不含私钥、令牌、生产数据库、第三方工具仓库或用户完整执行日志。将其放在工作区受忽略的位置，不要把本任务包全量注入AGENTS.md。

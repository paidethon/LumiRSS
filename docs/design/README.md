## Key principles

- Default theme: **Lumi Mist / 雾光** — warm-neutral, low-saturation, pale blue-indigo accent
- Semantic tokens only — no hard-coded colors in components
- App theme and Reader theme are independent
- Folo interaction parity, not Folo product parity

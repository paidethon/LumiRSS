## 阅读与时间线

- **全部信息源（首页时间线）**：按时间倒序展示你有权限阅读的全部来源
  条目。侧栏「阅读 → 全部信息源」，移动端为底部 tab「首页」。排序默认
  最新优先，可在设置改最早优先。**打开文章不会自动标为已读**——已读
  永远由你显式操作（或开启下文的自动已读选项）。
- **稍后读**：侧栏「阅读 → 稍后读」。在列表项或阅读页选「加入稍后读」，
  之后从该入口统一消化；与收藏互相独立。
- **收藏**：星标文章的统一视图。侧栏「阅读 → 收藏」；移动端另有底部
  tab。收藏跨来源聚合，不受订阅增删影响。

### Reader 工具栏

工具栏动作的排布与显隐可在「更多操作」里自定义，桌面与移动端各自记忆；
锁定动作（收藏、更多操作）不可移除，全隐藏会被拒绝。

| 动作 | 说明 |
|---|---|
| 收藏 | 星标/取消（set 语义写入 FreshRSS，不做盲目 toggle） |
| 打开原文 | 新标签页打开原始网页（安全协议 + 适当 `rel`）；Lumi 不代理原文 |
| 保存快照 | 存为网页快照防原文失效，归入「来源 → 网页快照」，可回看历史版本 |
| AI 对话 | 针对当前文章追问。前提：设置 → AI 已配置并分配 chat 用途（未配置诚实提示） |
| 语言视图 | 切换原文/译文展示（不动数据；翻译见 AI 节） |
| 文内查找 | 正文内查找关键词并逐个跳转，命中高亮 |
| 文中链接 | 列出文章全部链接逐条打开/复制；追踪参数按隐私设置清理 |
| 朗读 | 正文转语音（前提：分配 tts 用途，OpenAI 兼容 /audio/speech）；服务端缓存 50MB LRU，可在「数据控制 → 音频生成缓存」清理。听读音频导出（N099）当前不可用 |
| 分享 | 优先系统分享，不支持时诚实回退为复制链接 |
| 复制引用 | 「标题/来源/链接 + 选区引文」整理进剪贴板，纯文本或 Markdown，选区超 500 字截断 |
| 打印 | 浏览器打印/另存 PDF；只保留正文与元信息 |
| 位置校准 | 手动校正本机阅读位置记忆（按设备存储，不跨设备同步） |
| 媒体预算 | 查看并限制单篇文章媒体流量（大图/视频按次确认加载） |
| 更多操作 | 收纳低频动作 + 「自定义工具栏」重排/隐藏 |

### 阅读工具与行为（设置 → 阅读 / 通用）

- **翻页与滚动**：按屏翻页（步长 0.9 屏高；减少动效时瞬时翻页）、自动
  滚屏三档（切出页面自动停止）、回顶悬浮按钮、宽表格展开（实际溢出才
  出现控件）。
- **自动已读（默认关）**：读到正文末尾停留约 1 秒标为已读（只有主动
  滚动算进度，短文有「读完了」按钮）；或文章完全滚出列表上方后标已读
  （手动未读保护）。打开文章本身永不自动标读。
- **分页阅读模式**：CSS 多栏整页翻页 + 点按翻页方向/命中区配置；点
  链接、选文字、横滚表格不误翻。
- **键盘**：Alt+↑/↓ 在标题/链接/代码块/批注间跳转；外接键盘模式含
  按键测试目录；全局快捷键可在「设置 → 快捷键」捕获分配（与帮助弹窗
  同一份动作目录）。
- **时间线列表**：密度/摘要/封面/时间格式/排序/按日期或来源分组/已读
  变暗/启动仅未读（按来源分组只对已加载条目分组，诚实标注）。移动端
  卡片滑动操作（已读/稍后读/收藏，可关；左缘 24px 留给返回手势）。
- **手势练习**：在合成文章上演练侧滑返回等手势，只记台账不真实执行。

### 阅读样式

- 连续排版滑杆：字号/行距/段距/内容宽度/页边距（默认 17px/1.85/760px），
  与 Reader 内 Aa 面板共用同一份设置；
- 五个排版预设（默认 Lumi Mist、纸感、期刊衬线、AMOLED 真黑、高对比）
  + 派生自定义 + 导入导出；阅读背景色板 + 自定义 hex（文字色随背景
  WCAG 自适应）；
- 字体：四档字族 + WOFF2 上传（IndexedDB）或字体 URL；自定义 CSS 自动
  加 `.lumi-reader` 前缀只作用正文；主题包 `.lumitheme` 导入导出分享；
- 中文深度排版：首行缩进、标点悬挂（实验）、简繁转换（OpenCC，仅展示
  层字形转换）、阅读时间、词首强调（实验，bionic）；
- 选词词典：正文选词查词典。需自配查询端点；**未配置 = 零外发**（不向
  任何第三方发请求），入口如实说明；
- 连续阅读护眼提醒：计时在设备本地完成，不上报服务器。

### 界面外观（设置 → 外观 / 通用）

主题模式（浅色/深色/跟随系统）、强调色板与自定义取色（派生色自动生成
并做对比度校验）、界面字号与字体、玻璃效果、侧滑返回、减少动效（与
系统偏好叠加）。功能组合场景向导（如通勤听读）一键组合多项设置，diff
预览后应用，可整体撤销。

## 内容来源

九类来源统一入口在侧栏「内容来源 → 来源」（来源中心）：
**RSS 订阅 / RSSHub 路由 / API 来源 / 邮件桥 / 收件箱 / Obsidian /
书签 / 网页剪藏 / 网页快照**。

- **RSS 订阅**：原生 RSS/Atom，经 FreshRSS 拉取与管理。feeds/entries/
  已读/星标由 FreshRSS 持有。Feed 必须可从实例网络访问（私网地址受
  SSRF 策略诚实拒绝）。
- **RSSHub 路由**：把非 RSS 站点变成订阅源。前提：实例配置了
  `RSSHUB_BASE_URL`。RSSHub 只是 feed 生成器，条目库仍在 FreshRSS。
  实例级 RSSHub 地址/密钥配置在「设置 → RSSHub」（schema 驱动
  allow-list，机密只写不读，「重启后生效」明确展示）。
- **API 来源**：把 JSON API 变成 Atom 订阅（JMESPath 映射 → Atom →
  FreshRSS 订阅）。映射采样、预览、分页探测先验证再落配置。
- **邮件简报 / 邮件桥**：邮件列表归档视图 + 实例级邮件收信（IMAP）→
  清洗 → FreshRSS 订阅 + Atom。收信依赖运营者配置。
- **收件箱**：暂存待整理条目，规则（`GET/POST /api/v1/inbox/rules`）
  自动分流；推送入口为 bearer webhook（(source, guid) 幂等）。
- **书签 / 网页剪藏 / 网页快照**：保存 URL 供以后读（附链接有效性
  检查）；抓取网页正文存为剪藏（服务端 SSRF 代理 + 清洗管线，可重新
  抓取、保留修订）；文章或 URL 存为快照防失效（有版本可回看）。
- **Obsidian 库**：浏览 vault 笔记、反链、断链报告。读面**只读**；
  唯一写面是阅读页「更多操作 → 导出到 Obsidian」的受限导出（只写独立
  导出目录、绝不覆盖、每日配额）。多设备同步（P16）为 partial。

### 来源管理

- **OPML 导入 / 导出**：设置 → 订阅与来源。导出保留 RSSHub 路由映射；
  导入按内置路由元数据自动识别 RSSHub 路由（先实测有效再替换，原始
  地址留台账，可撤销）；上限 2 MiB，有日志。
- **统一来源注册表**：全部来源类型总览 + 健康状态 + 深链（设置 →
  订阅与来源）。陈旧来源检测（长期无更新/拉取失败）。
- **来源运维**（来源中心 → 来源运维）：批次接管（分类/归属迁移，可
  追溯）、暂停计划（按计划暂停/恢复某来源刷新）。
- **来源显示别名**：只影响本机的展示名替换，真实订阅名不变，有历史
  可回退。

## 整理与搜索

### 搜索

- **全局搜索**：跨全部条目的全文搜索（段落级命中）。侧栏「工具 →
  搜索」。搜索运行在派生可重建的投影上，不复制 FreshRSS 数据（原理见
  [architecture](/architecture#search)）。
- **高级筛选**：时间刷、拼写建议、语言过滤、排除词（持久生效）。
- **保存的搜索视图**：把一组条件存为视图，可置顶排序，可导出 Atom
  订阅。**Atom 地址含密钥 token，泄露即失效面，注意保管**。
- **同义词**：自定义同义词使命中变体写法；命中高亮（默认开）可在
  「设置 → 通用 → 搜索」调整。

### 工作区

把订阅/标签/筛选组织成不同阅读场景（侧栏「工具 → 工作区」）：改名/
说明/归档/导出/删除、阅读目标与达成条件、看板视图、模板复用。后端
没有的能力（图标/颜色、逐工作区默认排序）不做假开关。

### 标签与图谱

标签管理 + 关系图谱可视化（可保存为自定义视图）；**标签合并向导**
（先预览影响再执行，全程留日志）；标签组；标签同义词（统计与过滤
归一）。

### 过滤、快捷操作与队列

- **文章过滤规则**：按条件隐藏/降权列表条目（显示层过滤，不删除
  数据）；个人术语本参与 AI 翻译管线（需 AI 翻译才有实际效果）。
- **多步快捷操作**：把多个动作串成一条（定义在服务端，执行走各动作
  NORMAL 端点）。
- **阅读队列与阅读计划**：时段安排、前置条件、工作量、容量、提醒、
  主题分组——全部是「用户决策」模型，系统给建议，排队与计划由你确认。
- **批量归档**：多选条目按批次归档，先预览范围再执行，支持撤销。

### 批注与笔记

- **批注与精选篮**：正文选中即批注；可回复、分享、导出 Markdown；
  原文变化时可重锚定（re-anchor），锚定历史可查；批注按图层组织，
  整层导出迁移（先预览后应用）。
- **阅读笔记**：模板填充、附件、冲突检测、版本历史与回退。笔记在
  Lumi 自有库中，不写 Obsidian vault。
- **原文版本与引用**：同一文章原文变化的 diff 与来源时间线；抽取文中
  引用、构建引用链、生成证据核对清单。

## AI 功能

共同前提：在「设置 → AI」配置至少一个 Profile（OpenAI 兼容端点 +
密钥）并把用途（summary / translation / chat / tts）分配给它。
**未配置时相关入口诚实提示不可用，不会假装能用**；AI 失败永不阻塞
阅读。密钥只存服务端（write-only），永不下发浏览器、不回显。

- **配置与治理**：Profile 与用途分配（四个用途分别映射）；任务日志与
  重试（失败诚实可见，重试只对安全操作）；按用途的用量配额（日/月，
  超限任务被拒并如实报告）。
- **摘要**：为当前文章生成摘要，保留多版本并可指定激活版本，失败可
  重试；缓存命中与新生成在 UI 上明确区分。
- **翻译**：两种引擎——AI 翻译（需 translation 用途）与浏览器内置
  翻译（不支持的浏览器诚实提示 unsupported）。分段翻译与修订：单段
  重译、修订历史回滚、免翻段标记。
- **文章对话**：当前文章上下文多轮追问，支持批量提问与多篇对比。
- **阅读测验**：按文章内容出题并判分。
- **语义检索 RAG**：对全部条目建语义索引（sqlite-vec 单文件，无外部
  向量库）并问答，答案带证据。显式启用，索引可暂停/恢复/收敛/修复；
  侧栏「RAG 索引」看覆盖与排错。
- **Agent 工作台**：AI 会话 + 工具调用审批——每个工具调用先展示再
  批准，作用域受限，无静默执行；常用流程可存为配方复用。
- **AI 日报**：按配置定期把选题池生成日报，以 Atom feed 输出（任何
  阅读器可订）。OpenAI 兼容通道可用；Gemini 多提供方（P17）当前
  blocked。
- **简报工作台**：人工策展 + AI 起草的简报：选题、生成、修订溯源、
  确认、导出 eml、Atom 订阅。生成只是草稿，发布需显式确认。

## 账户与数据控制

### 账户（设置 → 账户）

- **资料与安全**：服务端核实的用户名与角色（头像/显示名/邮箱暂无
  服务端字段，不做假编辑）；改密码、Passkey、TOTP 两步验证、登出
  本机/全部会话（需要 session 模式；basic 模式下相关区块自动隐藏）。
- **数据导出**：工作区、标签、书签笔记与日报配置导出为版本化 JSON
  （不含密钥）。
- **会话管理**：设置 → 账户与安全列出有效会话（含"本机"标记），可
  撤销指定或全部。

### 数据控制（设置 → 数据控制）

- **完整备份与恢复**：账户数据的完整备份/恢复，支持 WebDAV 远端与
  备份历史（运营者级实例备份见 [operations](/operations#backup-restore)）。
- **偏好迁移**：导出/导入版本化偏好 JSON，diff 预览后才应用；个人
  数据迁出/迁入向导（zip 跨实例合并）。
- **设置历史与回退**：最近设置变更可单笔撤销（按字段冲突检查，已被
  后续修改的键如实跳过）；两台设备同时修改出现逐字段对照对话框，
  不静默覆盖。
- **存储与保留**：只读存储用量统计；派生数据保留策略默认关，启用后
  先预览（区分记录数与字节）再应用；原文、批注、笔记、卡片、凭据与
  运行中任务不受清理影响。
- **缓存管理**：本设备离线缓存配额（只删本设备 Cache Storage）；服务
  端 TTS 缓存查看与删除（50MB LRU）。
- **隐私**：逐来源数据外发清单（未配置 = 不发送）；登录事件/AI 任务
  日志/搜索快照可预览后清除；访问记录与边界、第三方请求清单、敏感
  资料标记、设备信任期限、授权撤销、共享链接范围与次数上限、删除
  范围预览与处理回执。隐私检查向导逐项撤回，**故意不做「一键全删」**。
- **长期保存**：书目导入、离线站点、JSON Feed、格式对照、加密导出、
  索引导出、分卷、逐项对账。
- **通知与帮助**：通知收件箱与聚合规则、静默时段、服务状态、处理单
  （工单）、文档反馈。

### 服务与诊断

- **服务健康页**（设置 → 服务）：BFF / FreshRSS / RSSHub / AI / 邮件 /
  Obsidian / RAG 的真实健康，五态语义（尚未检查 → 进程存活 → 接口
  可达 → 认证成功 → 业务可用）+ 错误详情。不做假绿灯。
- **能力可用性**（设置 → 关于 → 能力可用性）：区分「未配置」与「探测
  失败」，展示探测本身不产生费用。
- **关于**（设置 → 关于）：Web 与 BFF 的版本与构建信息，版本错配有
  诊断提示。
- **Library 回收站**：书签/剪藏删除先进回收站（可恢复）；永久删除需
  显式确认；FreshRSS 条目与 Vault 文件永不进入该流程。
- **本机草稿恢复**：笔记/批注编辑器未保存草稿留在本机（不上传）；
  意外关闭后重开提示恢复/放弃/对照，登出即清空。

## 管理台（/admin，owner/admin）

独立顶层路由 `/admin`，权限由服务端核实。成员邀请、注册策略、FreshRSS
池、暂停/恢复、密码重置的**操作手册**见
[operations](/operations#member-admin)。管理台还提供：

- **邀请方案**：把有效期/次数等参数存为方案模板，按方案批量生成邀请；
- **邀请容量**：当前实例还能发多少邀请的总览；
- **升级预览 / 升级进度 / 回滚就绪**：升级前预览变更、实时状态与回滚
  前置条件检查（部署操作本身见 [operations](/operations)）；
- **审计日志**：管理操作的审计记录；
- **运维工单**：成员提交的处理单在管理台分配/回复/关闭闭环。

## 方法论

### 固定场景组合（mixed load）

`tools/perf/load-soak.mjs` 对生产级 e2e 栈（`e2e/stack/docker-compose.e2e.yml`，
经 web/Caddy 入口 `BASE_URL` 访问，与浏览器同一路径）施加以**固定权重轮转**的
认证负载，每次循环迭代按以下组合选择场景：

| 场景 | 权重 | 请求 |
|---|---|---|
| 条目列表 | 60% | `GET /api/v1/entries` |
| 打开条目详情 | 20% | `GET /api/v1/entries/{entryRef}` |
| 搜索 | 10% | `GET /api/v1/search?q=…&limit=20` |
| 工作区列表 + 加入/移除条目 | 10% | `GET /api/v1/workspaces` + `POST /api/v1/workspaces/{id}/items` + `DELETE …/items/{ref}`（加后即删，不增长数据） |

所有请求都携带会话 cookie（登录一次复用；401 时自动重登并重试一次），
且经 CSRF 所需的同源 `Origin` 头 —— 与真实客户端一致。权重是确定性轮转
（非随机抽样），因此整个跑动窗口内的全局比例精确等于 60/20/10/10。

### 阶段划分：warmup → steady → report

- **warmup**（默认 60s）：以同样负载预热缓存/JIT/连接池，其数据单独聚合、
  不进入结论；资源采样同样分阶段记录（warmup 末段的内存水平可近似视作
  该场景下的"热稳态"参考）。
- **steady**（`DURATION_S`，默认 300s）：唯一用于结论的测量窗口。
- **report**：聚合结果写入 `tools/perf/reports/soak-<ts>.json` 并打印摘要。
  内存上无界增长的结构一律不存在：延迟用固定大小的 log2 分桶直方图
  逐请求增量聚合；容器采样增量汇总，保留序列原地抽稀（上限 600 点）。
  SIGINT 中止时仍写出最终报告（退出码 130）。

### 指标定义（诚实口径）

| 指标 | 口径 |
|---|---|
| p50 / p95 延迟 | **客户端观测**：从驱动进程发起请求到收到完整响应（驱动 → web/Caddy → BFF 全链路）。本工具**不**单独测服务端处理耗时——那需要 BFF 内打点；两者之差包含代理与回环网络开销，对比时须说明口径。分位数来自 ~3.5% 相对宽度的 log2 分桶直方图，桶内线性插值，非逐值精确排序 |
| 错误率 | 非 2xx 状态、网络错误、超时。401 触发重登后重试，仅计入最终结果的端点指标；重登次数单独记录在 `meta.reAuths` |
| 容器 CPU | `docker stats` 的 `CPUPerc`（容器 cgroup 用量相对**单核**的百分比：100% = 1 个核心，多核容器可 >100%；1s 目标间隔采样。注意 `docker stats` CLI 每次调用本身耗时 ~1–2s，实际采样周期约 2s，报告中的 `samples` 数如实反映） |
| 容器内存 | `docker stats` 的 `MemUsage` 当前值（cgroup 当前内存，含页缓存，非进程 RSS 精确值；更接近"容器工作集"）。报告区分 min/avg/max |
| cgroup 限额 | e2e 栈**不**设内存/CPU 限额（测的是 BFF 进程行为，不是机器）；生产 compose 才有 `mem_limit`/`cpus`。因此 e2e 跑出的内存数字不能直接对照生产限额解读 |
| 空闲工作集 | 无用户负载时 BFF 容器内存的稳定水平（生产口径：2C/2G 部署、启动完成 + 首次同步收敛后采样） |

### 与生产目标环境的关系

**开发机 e2e 跑出的数字只是该机器上的"before/after"对比基线**——不是
2C/2G 目标环境的测量结果。发布门（gate D）须在部署候选构建上、按目标
资源画像（2 vCPU / 2 GiB，或 compose 注入的等价限额）重跑并记录。

## 工程目标（ENGINEERING TARGETS — 非实测结果）

下表是**设计目标**，用于判定部署候选是否可接受；它们不是已测得的数字，
也不构成任何保证：

| 指标（2C/2G 生产画像） | 目标 |
|---|---|
| BFF 空闲工作集 | ≤ 1.2 GiB |
| BFF 混合负载峰值内存 | ≤ 1.6 GiB |
| 空闲 CPU | ≤ 5% |
| 轻量 API p95（列表/详情/搜索/工作区） | ≤ 300 ms（客户端观测口径） |
